Compare the SHA-256 above with the build hashes published in the JRock repository (and optionally download the JAR to hash it yourself), then press Run JRock. Your Bedrock region and API key go into JRock's own Configure dialog, exactly as on the desktop: they are kept in this browser's storage, so they are still there after a reload.

A few seconds after JRock starts, this page's header and footer are hidden so the app gets the whole tab. To bring them back - to check the checksum, or to read the page's own log - long-press, or right-click, the empty area at the top of JRock's window and choose Show/hide the page header & footer.

Runs unmodified JRock Java bytecode via CheerpJ (WebAssembly + JS). Bedrock calls go out through this page's own HTTP fetch(), with the API key JRock holds: put it into JRock's Configure dialog - that row is unmasked here and has its own Paste button - and it is saved in /files/JRock/bedrock-key.txt inside this browser's own storage, where a reload finds it again. A short-term key can be generated in the AWS console. Use a Java window's title-bar upload button to load a local file into /files/uploads/; anything JRock saves under /files/downloads/ is downloaded to your machine.
