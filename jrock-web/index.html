Runs unmodified Java bytecode in the browser via CheerpJ (WebAssembly + JS). Must be served over HTTP (not opened as a file://). Outbound Bedrock calls are subject to browser/CheerpJ network limits, so this page is intended for testing the JRock UI locally.
