Verify the checksum above (and optionally download the JAR to check it yourself). Optionally set your Bedrock region and API key with the 🔒 button, then press Run JRock.
Runs unmodified JRock Java bytecode via CheerpJ (WebAssembly + JS). Use a Java window's title-bar upload button to load a local file into /files/uploads/; anything JRock saves under /files/downloads/ is downloaded to your machine. Outbound Bedrock calls will almost certainly fail in a standard browser: CheerpJ has no native socket layer, so HttpClient's networking (sun.nio.ch.EPoll) is unavailable and throws UnsatisfiedLinkError. Run the desktop jar for live Bedrock calls.

Bedrock credentials

Passed to JRock as the AWS_REGION and BEDROCK_API_KEY JVM properties when you press Run. They stay in this browser tab and are never sent anywhere except directly to the Bedrock endpoint by JRock itself. A short-term key (tied to its region) can be generated in the AWS console.
