Runs unmodified JRock Java bytecode via CheerpJ (WebAssembly + JS). Bedrock calls go out through this page's own fetch(), because CheerpJ has no native socket layer for Java's HttpClient: your region and API key stay in this tab's JavaScript (window.myBrowserHttp) and are sent only to the Bedrock endpoint. Use a Java window's title-bar upload button to load a local file into /files/uploads/; anything JRock saves under /files/downloads/ is downloaded to your machine.

Bedrock credentials

Held by this page's HTTP client (window.myBrowserHttp), which performs JRock's requests and adds the Authorization header itself - the key is never handed to the in-browser JVM, and never sent anywhere except directly to the Bedrock endpoint. You can change the key at any time; the region is picked up by JRock when it starts, and after that can be changed in JRock's own Configure dialog. A short-term key (tied to its region) can be generated in the AWS console.
